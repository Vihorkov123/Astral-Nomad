# Астральный скиталец (Astral Nomad)

2D top-down sci-fi survival / rogue-lite на чистом Vanilla JS + HTML5 Canvas.
Без сборщиков, без фреймворков, без внешних зависимостей. Полный сюжет:
пролог, 4 акта, босс «Хранитель» и две концовки.

Лейтенант Кай Сон — последний выживший с «Ковчега-6». Исследуй звёзды,
вскрывай древние сундуки, выбирай между безопасностью и риском, дерись
ножом с тенями и узнай, что на самом деле перевозил «Ковчег».

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Движение |
| E | Удар ножом / открыть сундук / капсула |
| Пробел | Рывок (неуязвимость, быстрые монстры теряют цель) |
| Q | Аптечка (+8 ОЗ) |
| Esc | Пауза |

## Механики

- **Сундуки.** Маленькие — скромный лут, 20–32% шанс быстрого «Жука-искры».
  Большие — лут ×3 и редкая деталь, 55–72% шанс «Гниющего рыцаря».
  Перед открытием видны шансы — риск выбираешь сам. Если монстр появился,
  он удерживает лут: награда (с бонусом ×1.5) выпадает только после победы.
- **Прогрессия.** 5 звёзд открываются последовательно (нужно вскрыть N
  сундуков на текущей). Дальше — больше карта, больше сундуков, сильнее монстры.
- **Хранитель.** Вскрыть все 5 сундуков на «Шепчущих вратах» — призвать босса.
  Щит непробиваем: бей в окно уязвимости после серии его ударов.
  Награда — артефакт «Сердце Ковчега».
- **Смерть.** Теряется вся еда, 30% золота и одна деталь. Золото (остаток)
  и открытые звёзды сохраняются. Респаун — на текущей звезде, открытые
  сундуки не сбрасываются.
- **Голод.** Еда тратится со временем; на нуле здоровье тает. У капсулы
  можно отдохнуть (−1 еда, +10 ОЗ) — тени отступают, но их добыча теряется.
- **Концовки.** На «Пустоте внутри» центральный сундук даёт выбор:
  уничтожить всё (финал) или открыть правду — и получить бесконечную
  карту звёзд с процедурной генерацией.

## Запуск локально

Нужен любой статический HTTP-сервер (открытие `index.html` двойным кликом
не подойдёт — браузеры режут localStorage/автозагрузку на `file://`).

Вариант 1 — Python (есть почти везде):

```bash
cd Astral-Nomad
python3 -m http.server 8080
# открыть http://localhost:8080
```

Вариант 2 — Node.js:

```bash
npx serve .
```

Вариант 3 — VS Code: расширение **Live Server** → правый клик по
`index.html` → «Open with Live Server».

## Тесты

Смоук-тест игровой логики (мир, сундуки, бой, смерть, босс, сейвы) без браузера:

```bash
node scripts/smoke-test.js
```

## Интеграция с Яндекс Играми

- `js/sdk.js` динамически подключает `/sdk.js`: на площадке Яндекса SDK
  работает (облачные сейвы через `player.setData/getData`, `LoadingAPI.ready`,
  `GameplayAPI.start/stop`), локально — тихий fallback на `localStorage`.
- Автопауза: `visibilitychange`, `blur/focus`, `pagehide` и события
  `game_api_pause/resume` останавливают игру и звук.
- Конфликт облако/локаль решается в пользу большего прогресса.

Локальная проверка с реальным SDK:

```bash
npm i -g @yandex-games/sdk-dev-proxy
sdk-dev-proxy -p . --app-id <ID_игры>
# открыть выданный https-адрес
```

Сборка для загрузки в консоль разработчика — просто zip без лишнего:

```bash
zip -r astral-nomad.zip index.html css js
```

## Структура

```
index.html        — разметка, экраны UI, порядок подключения скриптов
css/style.css     — весь интерфейс (русский, адаптив под любой аспект)
js/util.js        — математика, детерминированный ГПСЧ
js/stars.js       — конфиги 5 звёзд + генератор бесконечных
js/story.js       — все сюжетные тексты (пролог, акты, концовки)
js/sdk.js         — мост Yandex SDK: автопауза, сейвы, fallback
js/save.js        — модель сохранения, дебаунс, слияние прогресса
js/audio.js       — WebAudio: процедурные SFX и эмбиент (0 аудиофайлов)
js/input.js       — клавиатура по event.code (не зависит от раскладки)
js/world.js       — генерация карты звезды, коллизии
js/entities.js    — игрок, монстры, ИИ
js/ui.js          — экраны, диалоги с печатной машинкой, HUD, карта звёзд
js/game.js        — состояния, бой, сундуки, смерть, рендер
js/main.js        — загрузка, игровой цикл, ресайз
scripts/smoke-test.js — автотест логики на Node
```
